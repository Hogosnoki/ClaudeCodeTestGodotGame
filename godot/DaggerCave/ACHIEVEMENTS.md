# Dagger Deep: achievements (Steamworks order)

Progress achievements are party-wide and visible; feats are hidden and each player's own unless marked *(party)*.
Steam's own completion count includes every achievement; the game's counts progress only.

## Feats (22, hidden)

| API name | Name | Description |
| --- | --- | --- |
| `ACH_POWER_HUNGRY` | Power Hungry! *(party)* | Open every upgrade shrine in a depth (the level's, the mini-bosses', the hive's and the guardian's). |
| `ACH_LOOTER` | Looter! *(party)* | Open every chest in a depth: relic chests, collections, vaults and the hidden ones. |
| `ACH_RANSACKED` | Ransacked! *(party)* | Open every shrine and every chest in a depth. |
| `ACH_OBLITERATED` | Obliterated! | Fall to a single blow from full health. |
| `ACH_UNBREAKABLE` | Too Stubborn to Die | Survive a blow that exceeds your maximum health. |
| `ACH_SAVIOR` | Savior | Revive your friends 10 times in a single run. |
| `ACH_BURDEN` | Burden | Be revived 10 times in a single run. |
| `ACH_FISH_KIN` | Fish-Kin | Stay under water for 2 minutes on the rising bubbles' air alone (not as a creature, nor in a bubble, nor without lungs). |
| `ACH_NOT_FAIR` | Not Fair | Be felled by the Glitch. |
| `ACH_HORRORS` | Indescribable Horrors! *(party)* | Defeat the Glitch. |
| `ACH_UNTOUCHABLE` | Untouchable! | Take no damage at all for a whole depth (chip through a shield counts). |
| `ACH_UNDEFEATABLE` | Undefeatable! *(party)* | Complete a run in which nobody in the party fell. |
| `ACH_HEAVY_HITTER` | Devastating Blow! | Deal 500 damage in a single strike. |
| `ACH_DOUBLE_SPEED` | Fleet of Foot | Reach double your hero's movement speed. |
| `ACH_MAX_FALL` | Hard Landing | Take the most a fall can take. |
| `ACH_CHAIN_REACTION` | Chain Reaction | Shatter 5 or more creatures with a single snap. |
| `ACH_GLASS_CANNON` | Glass Cannon | Complete a run carrying both Glass Edge and Heavy Hand. |
| `ACH_HOARDER` | Hoarder | Carry 300 gold at once. |
| `ACH_MINIMALIST` | Minimalist | Slay the dragon having taken no more than 5 upgrades. |
| `ACH_TIGHT_SQUEEZE` | Tight Squeeze | As the Shape Shifter, slip into a hidden chamber only a creature can reach. |
| `ACH_SPIKE_DANCER` | Spike-Dancer | Defeat the Barrow King without it ever striking you. |
| `ACH_BRAWLER` | Brawler *(party)* | Defeat the Goblin Warchief with nobody in the party falling during the fight. |
